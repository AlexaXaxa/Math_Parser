## Features
- Zoom, pan
- Evaluate expressions: `5+5` or `sin(4) + 5`
- Plot in explicit form y=... like `y = x + 1` or horisontal lines like `y = 5`
- Vertiсal lines: `x = 5`
- Variables and calculation with them: `a = 5`,  `y=5`
- Colorfull lines
- Manual
- Music player
- Feedback
  
## Future Features
- Power (x^2, x^3...)

## Future-Future Features :)
- Algebra

- f(5)
  
## How to Run
1. Make sure you have Visual Studio 2022 installed.
2. Make sure the required .NET version (.NET 9.0) is installed.
3. Clone this repository and open the MathParser_1.0.sln file in Visual Studio.
4. Press Run (F5) to start the application.
